# Instructions for AI coding and review tools

Follow `CLAUDE.md` in the project root, plus `app/CLAUDE.md` and `frontend/CLAUDE.md` for those folders.
- Process and gates: `docs/PROCESS.md`
- Architecture, time/slot/booking rules, status changes, API: `docs/ARCHITECTURE.md`
- When reviewing a pull request, check it against its spec in `docs/specs/` (the `Branch:` line matches the PR branch),
  including the spec's test case IDs and `## Test results`.
- Never add AI attribution lines to commits or PR text.
